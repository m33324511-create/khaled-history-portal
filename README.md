# Mr. Khaled Ibrahim — History Portal

واجهة عربية متجاوبة لبوابة التاريخ التعليمية، بهوية مصرية تاريخية مستقبلية وألوان متناسقة (كحلي، تركواز، مرجاني، ودرجات فاتحة). تتضمن الوضع الفاتح والداكن، صفحة رئيسية تعريفية، صورة الأستاذ، ونافذة دخول الطلاب بثلاثة حقول.

## تشغيل الواجهة محليًا

يمكن فتح `public/index.html` مباشرة لمعاينة التصميم. لا يعمل تسجيل الدخول الحقيقي إلا بعد نشر المشروع على Cloudflare Pages وربط قاعدة D1 وإعداد السر.

## النشر على GitHub وCloudflare Pages

1. ارفع محتويات المجلد إلى مستودع GitHub.
2. أنشئ مشروع Cloudflare Pages واربطه بالمستودع.
3. اجعل Build command فارغًا، ومجلد الملفات الناتجة `public`.
4. من إعدادات Pages اربط قاعدة D1 باسم binding: `DB`.
5. استبدل `database_id` في `wrangler.toml` بمعرّف قاعدة D1 الفعلي.
6. نفّذ ملف `db/schema.sql` على قاعدة D1 لإنشاء الجداول.
7. أضف متغيرًا سريًا باسم `SESSION_SECRET` بقيمة عشوائية طويلة في إعدادات Pages Functions.

## الموجود في هذه النسخة

- واجهة رئيسية responsive باللغة العربية مع العبارة الإنجليزية: “WELCOME TO MR. KHALED IBRAHIM'S HISTORY PORTAL”.
- صورة الأستاذ المرفقة في الواجهة.
- تبديل الوضع الفاتح والداكن مع حفظ اختيار الزائر.
- نافذة دخول الطالب بثلاثة حقول: الاسم، الهاتف، الرقم التعريفي.
- Pages Function للتحقق من بيانات الطالب المسجل مسبقًا في D1 وإصدار cookie جلسة موقّع.
- مخطط قاعدة بيانات أولي للمديرين والطلاب والمجموعات والامتحانات والأسئلة والمحاولات والإجابات وسجل العمليات.

## ما لم يكتمل بعد

هذه نسخة تأسيسية للواجهة وربط دخول الطالب. لوحة الإدارة الفعلية، إدارة المشرفين والصلاحيات، إدارة الطلاب والمجموعات، منشئ الامتحانات، صفحات أداء الامتحان، النتائج، وسجل المحاولات تحتاج استكمالًا قبل استخدامها تشغيليًا. لا تُدخل بيانات طلاب حقيقية قبل استكمال هذه الأجزاء واختبارها.

## ملاحظة أمنية مهمة

الدخول بالاسم ورقم الهاتف والرقم التعريفي يطابق الحقول المطلوبة، لكنه لا يثبت هوية الطالب إذا كانت هذه البيانات معروفة للغير. قبل الإطلاق الفعلي أضف تحديد معدل محاولات الدخول، وسيلة تحقق إضافية عند الحاجة، ونقطة API آمنة لقراءة الجلسة وتسجيل الخروج. لا تضع أسرارًا أو كلمات مرور داخل ملفات الواجهة.
